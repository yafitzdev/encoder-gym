## [0.1.0] - 2026-09-15

### Added

- Local encoder-development workflow spanning data generation, curation,
  training, evaluation, error analysis, and iterative improvement.
- Agent-oriented dataset and benchmark tooling with bounded execution and
  explicit review boundaries.
- Rust CLI for project setup, workflow execution, recovery, verification, and
  provenance inspection.
- Desktop interface for managing local projects, datasets, models, runs, and
  comparisons.
- SQLite persistence, immutable artifact lineage, resumable operations, and a
  deterministic offline demo.
